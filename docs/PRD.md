# PRD: 문장 카드뉴스 (가칭 CardNote)

## 1. 한 줄 소개
유튜브 채널 **라이브 아카데미(@LVACDMY)** 영상 URL을 넣으면, 영상에서 가르치는 영어 문장과 핵심 표현을 **핵심 카드**로 모아 보게 해 주는 웹앱.

## 2. 배경과 목표
- 라이브 아카데미 영상은 "영어 뇌 만들기 문장 5개"처럼 **영상 하나에 영어 문장 여러 개**를 한국어 해설과 함께 가르친다.
- 영상을 보고 나면 문장이 흩어져 기억에 남지 않는다. 영상별로 문장을 **핵심 카드 한 장**에 모으고, 한국어나 영어를 가리고 떠올려 보며 공부하게 한다.
- 운영비 0원: Vercel Hobby + Supabase 무료 + Gemini 무료 등급.

## 3. 사용자
- 이 채널로 영어를 공부하는 한국어 사용자. 구글 계정으로 로그인한다.

## 4. 핵심 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 영상 내용 가져오기 | **Gemini에 YouTube URL을 직접 전달**(`fileData.fileUri`) | 공식 기능이고 다운로드가 필요 없다. 화면 자막과 한국어 해설까지 이해한다. 10분 영상 기준 약 13초, 영상 토큰 약 5만 개(저해상도). |
| 쓰지 않는 방법 | YouTube Data API 자막(소유자만 가능), 비공식 자막 스크래핑, 오디오 다운로드 | 권한·약관 문제, 클라우드 IP 차단 |
| 받는 영상 | **@LVACDMY 채널의 공개 영상만** | 프롬프트를 채널 형식에 맞춰 품질을 높이고, 무료 한도 남용을 막는다. 채널 확인은 YouTube oEmbed(키 불필요)로 한다. |
| 로그인 | 구글 로그인(Supabase Auth) | 내가 본 영상과 핵심 카드를 계정에 저장해서 기기를 바꿔도 이어 간다. |
| 저장 | **새 Supabase 프로젝트** | 기존 ListenUp과 분리한다. |
| 결과 공유 | 같은 영상의 카드뉴스는 **한 번만 만들고 모든 사용자가 같이 본다** | 공개 영상이고, Gemini 호출을 아낀다. |

## 5. MVP 기능

### F1. 로그인
- 구글 로그인과 로그아웃. 로그인하지 않으면 첫 화면 소개와 로그인 버튼만 보인다.
- 핵심 카드 보기와 만들기는 로그인해야 쓸 수 있다.

### F2. 영상 URL로 카드뉴스 만들기
- 입력: `youtube.com/watch?v=`, `youtu.be/`, `youtube.com/shorts/`, `youtube.com/live/` 형식의 URL 또는 영상 ID.
- 검사 순서
  1. 영상 ID 추출. 실패하면 "올바른 유튜브 주소가 아니에요".
  2. oEmbed로 채널을 확인한다. 작성자 URL이 @LVACDMY(또는 채널 ID `UCGDA1e6qQSAH0R9hoip9VrA`)가 아니면 거절. 비공개·삭제된 영상도 여기서 걸러진다.
  3. 이미 만들어진 카드뉴스가 있으면 Gemini를 부르지 않고 바로 연다.
  4. 다른 사람이 만드는 중(5분 이내)이면 "만드는 중"이라고 알리고 기다린다.
  5. 하루 한도 확인: 앱 전체 하루 생성 한도(`DAILY_GENERATE_LIMIT`, 기본 400)와 사용자별 하루 한도(`USER_DAILY_LIMIT`, 기본 10).
- Gemini 호출 1회로 요약과 카드 내용을 JSON으로 받는다(모델은 `GEMINI_MODEL`, 기본 `gemini-3.5-flash-lite`, 저해상도 영상 모드).
- 안정성(ListenUp에서 얻은 교훈)
  - 503 high demand는 3초, 10초 쉬고 두 번까지 다시 시도한다(남은 시간이 있을 때만).
  - 호출 하나에 시간 제한 240초. 함수 최대 시간은 300초.
  - 성공, 실패, 한도 초과, 재시도를 **시도마다** `gemini_log`에 남긴다(구글은 실패와 재시도도 한도에 센다).
  - 429 하루 한도는 "오늘 무료 한도를 다 썼어요", 분당 한도와 붐빔은 "잠시 후 다시"로 구분해서 알린다.
  - 회원 전용 영상처럼 Gemini가 읽지 못하거나 문장이 0개면 실패로 처리하고 이유를 보여 준다.

### F3. 문장 정리 보기 (`/v/[videoId]`)
- 한 장짜리 핵심 카드(Wrap up): 영상 제목과, 영상에서 배운 영어 문장을 **한국어 뜻과 나란히** 번호 순서로 보여 준다.
- 문장마다 발음 듣기(브라우저 TTS). 문장별 장면 재생은 넣지 않는다(사용자 결정).
- 카드에 **▶ 영상 보기** 버튼 하나: 누르면 원본 영상을 YouTube 공식 임베드 플레이어 창으로 띄운다.
- 영어 문장 안의 **핵심 표현은 형광펜 색(노랑)**으로 구분해 보여 준다.
- **한국어 가리기 / 영어 가리기** 버튼: 한쪽을 흐리게 가리고 떠올려 본다. 가린 줄은 눌러서 하나씩 볼 수 있다.
- 아래에 원본 영상과 채널 링크(출처).
- **핵심 카드 모아 보기** (`/cards`): 내가 정리한 영상을 채널 업로드 순서(오래된 것부터)로, 제목만 있는 작은 카드로 늘어놓는다. 누르면 그 카드만 크게 펼쳐서(문장 목록, 가리기, 발음) 보여 준다. 홈에는 최근에 연 핵심 카드 4개와 "전체 보기" 링크를 둔다.
- 처음에는 가로로 넘기는 카드뉴스(표지 → 문장별 카드 → 마무리)로 만들었으나, 사용자 피드백으로 마무리 카드 하나로 줄였다.
  요약·핵심 표현·해설·응용 예문은 계속 만들어 저장하지만 화면에는 보이지 않는다(핵심 표현은 영어 문장 안에서 노란색으로 표시된다).
- 핵심 카드를 열면 자동으로 내 목록에 추가되고 "본 영상"으로 표시된다.

### F4. 복습 (뺌)
- 처음에는 간격 반복(SRS) 플래시카드 복습을 넣었으나, 사용자 결정으로 뺐다. 공부는 핵심 카드의 한국어/영어 가리기로 한다.

### F5. 홈
- URL 입력창과 "카드뉴스 만들기" 버튼.
- **이어서 볼 영상**: 채널 전체 영상(오래된 순)에서, 내가 연 영상 중 가장 나중 것의 바로 다음 영상.
- **채널 전체 영상 목록**(YouTube Data API 업로드 재생목록, 업로드 날짜가 오래된 순, 약 1,500개). 20개씩 페이지로 나누고, 처음에는 이어서 볼 영상이 있는 페이지를 연다. 제목 검색, **전체 / 본 영상 / 남은 영상** 거르기 버튼(내가 연 영상 기준). 이미 정리된 영상은 "보기", 아니면 "정리하기", 내가 연 영상은 "✓ 봤어요".
- 목록은 6시간 동안 캐시한다(한 번 불러올 때 약 30유닛). `YOUTUBE_API_KEY`가 없으면 목록 대신 안내 문구를 보여 준다.
- 오늘 Gemini 사용량(앱 전체 n/한도, 나 n/한도).

## 6. 저작권·약관 원칙
- 영상 대본 전문이나 해설을 그대로 옮겨 저장하지 않는다. 저장하는 것은 영상이 가르치는 **학습 문장**(짧은 문장), AI가 **자기 말로 쓴 짧은 요약과 해설**, AI가 **새로 만든 예문**뿐이다.
- 영상은 YouTube **공식 임베드 플레이어**로만 재생한다. 다운로드, 광고 제거, 회원 전용 영상 처리는 하지 않는다.
- 모든 카드뉴스에 출처(채널 이름, 원본 영상 링크)를 표시한다.
- 개인 학습용으로 운영한다. 공개 서비스로 키울 때는 채널에 허락을 받는다.

## 7. 데이터 모델 (Supabase)
- `decks`: video_id(PK), title, author, thumbnail_url, status(processing/ready/failed), content(jsonb: 요약과 카드), model, error, created_by, started_at, created_at, updated_at
- `user_decks`: user_id, video_id, last_opened_at (PK user_id+video_id)
- `gemini_log`: id, created_at, user_id, video_id, model, status(ok/error/rate_limited), message, input_tokens, output_tokens
- 모든 표에 RLS를 켜고 정책은 두지 않는다. 서버만 secret key로 접근하고, 사용자는 쿠키 세션으로 확인한다.

## 8. 화면 목록
`/`(홈, 비로그인 시 소개), `/v/[videoId]`(핵심 카드), `/cards`(핵심 카드 모아 보기), `/auth/callback`(로그인 콜백)

## 9. 범위 밖 (나중에)
관리자 페이지, 영작 입력 채점, 다른 채널 지원, 카드 직접 편집, 이미지로 저장 및 공유, 재생목록 한 번에 처리.

## 10. 완료 기준
- 위 F1~F5가 로컬(`npm run dev`)에서 동작한다.
- `npm run build`와 `npm run lint`가 통과한다.
- README에 Supabase 및 구글 로그인 설정, 환경 변수, Vercel 배포 방법이 정리돼 있다.
